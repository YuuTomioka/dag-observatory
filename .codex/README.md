# Codex Workspace Notes

This directory holds AI-local workflow helpers for this repository.

## Role

- short operating notes for AI pair-programming flows
- reusable task checklists or templates that do not become structural source of truth
- local helper material that points back to durable docs

## Non-Goals

- do not treat `.codex/` as the source of truth for repository structure
- do not duplicate `blueprint/`, `governance/`, or implementation docs here
- do not move long-lived decisions here

## Usage Rule

When a `.codex/` note conflicts with `blueprint/`, `governance/`, or root `AGENTS.md`, the durable repository docs win.
