# Governance

このディレクトリは、このリポジトリにおける人間向けの運用面を集約する入口です。

## 役割

- 変更の扱い方と文書配置ルールを定義する
- 人間向けの依頼、ハンドオフ、報告の入口を揃える
- 一時的な共有文脈と、再利用可能な運用面を分離する

## 使い分け

### `policies/`

リポジトリ全体で守る変更ルール、文書配置ルール、言語方針を置きます。

### `contracts/`

変更要求、実装タスク、検証報告のような、人間同士の受け渡しテンプレートを置きます。

### `guides/`

反復して参照する人間向けの進め方、操作手順、文書の使い分けを置きます。

### `tasks/`

案件ごとの一時的な共有作業文脈を置きます。恒久的なルールや再利用テンプレートは置きません。

## 原則

- 構造や仕様の正本は `blueprint/`、`implementations/`、`platform/`、`data/` に置く
- `governance/` は人間向けの運用面を集約するが、技術的な正本は再定義しない
- 日本語文書は英語の正本を参照し、重複した真実を作らない
- 命名、フォーマット、ライフサイクルの局所ルールは各サブディレクトリの `README.md` に置く
