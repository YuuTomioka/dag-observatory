# Contracts

このディレクトリは、人間向けの要求受理、実装ハンドオフ、検証報告のテンプレートを置く場所です。

## 役割

- 依頼内容を共有可能な形へ正規化する
- 設計判断から実装、検証までの受け渡し面を揃える
- 英語の正本ドキュメントを参照しつつ、日本語で人間向けインタフェースを提供する

## ルール

- テンプレートの本文は日本語を基本とする
- 構造や仕様の正本はここに書かず、必要な場合は `blueprint/`、`implementations/`、`platform/`、`data/` を参照する
- 一時的な案件固有の作業文脈は `governance/tasks/` に置き、ここには再利用テンプレートだけを置く

## 命名方針

- テンプレート名は役割がひと目で分かるものにする
- `change-request.md`, `implementation-task.md`, `validation-report.md` のように、対象と用途を直接表す
- `template.md` や `misc.md` のような汎用名は避ける

## フォーマット方針

- 見出しは固定し、利用者が毎回同じ順で記入できるようにする
- 1テンプレートは1用途に限定する
- 必要なら「参照すべき正本ドキュメント」を明示する欄を持たせる

## ライフサイクル方針

- 繰り返し使う受け渡し面だけをここに置く
- 一案件専用に崩した内容は `governance/tasks/` で扱う
- テンプレートが安定しないうちは最小限の項目に留める
