# Guides

このディレクトリは、人間向けの運用ガイドと進め方をまとめる場所です。

## 置くもの

- 反復して使う進め方
- 文書やテンプレートの使い分け
- operator や contributor が参照する日本語の手順

## 置かないもの

- 構造や仕様の正本
- 案件固有の一時メモ
- 実装固有の詳細仕様

## 使い分け

- 依頼・ハンドオフ・報告テンプレートは `governance/contracts/`
- 一時的な作業文脈は `governance/tasks/`
- 検証導線や代表フローは `scenarios/`

## 命名方針

- ガイド名は対象と用途が分かる形にする
- `task-writing-guide.md`, `validation-flow-guide.md`, `document-routing-guide.md` のように、何の進め方かを名前に含める
- 抽象的な `guide.md` や `howto.md` のような単独名は避ける

## フォーマット方針

- 最初に対象読者と利用場面を明示する
- 手順、判断基準、参照先を分けて書く
- 技術的な正本を説明し直すのではなく、どこを読めばよいかを案内する

## ライフサイクル方針

- 反復して参照される進め方だけをここへ昇格する
- 一時的な案件対応や検討メモは `governance/tasks/` に留める
- ガイドが恒久ルールに変わる場合は `governance/policies/` へ昇格する
