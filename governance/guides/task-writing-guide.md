# タスク文書作成ガイド

## 対象読者

- contributor
- repository maintainer

## 使う場面

- `governance/tasks/` に新しい task document を作るとき
- 既存 task document を更新またはクローズするとき

## 作成の基本

- 1ファイル1トピックで作る
- 日本語を基本にする
- 命名は topic と役割が分かる形にする
- 正本の再定義ではなく、共有文脈をまとめる

## 必須項目

- background
- in-scope
- out-of-scope
- acceptance criteria
- result

## あるとよい項目

- references
- next actions
- promotion target

## 更新の仕方

- topic が継続している間は同じファイルを育てる
- 完了したことと残件を区別して書く
- durable conclusion が出たら proper location に昇格する

## クローズの判断

- temporary context が不要になった
- 重要な結論が適切な正本へ昇格済み
- 後続が読んでも誤解しない状態に整理できている
